# Beginner's Running Guide

You do NOT need to install Python before you begin learning.

## Option A — learn the basics in a browser
1. Open Google Colab: https://colab.research.google.com/
2. Choose **New notebook**.
3. Type a small Python statement such as `print("Hello")` into a code cell.
4. Press the play/run icon beside the cell.
5. Learn variables, lists, conditions, loops, functions, and then Pandas.

Google Colab is suitable for learning Python, but this dashboard uses Streamlit, so it needs a Streamlit-compatible environment to display the full interactive web app.

## Option B — run the full dashboard
1. Extract the ZIP file on your computer.
2. Keep `app.py`, `requirements.txt`, and the `data` folder together.
3. Use a Streamlit-compatible cloud deployment service, or install Python and the requirements later with help from a teacher/mentor.
4. Upload the project files and launch the Streamlit app according to that service's instructions.
5. Open the provided web app URL and explore the filters, charts, and download button.

## Dataset
The included data is fictional. For real school marks, get permission, remove unnecessary personal details, and use student IDs rather than full names where possible.

## Suggested learning order
1. Python print, variables, numbers, and strings
2. Lists, loops, `if` statements, and functions
3. CSV files and Pandas DataFrames
4. Bar charts and histograms
5. How Streamlit displays tables, filters, metrics, and charts
6. How to test the dashboard with changed data
