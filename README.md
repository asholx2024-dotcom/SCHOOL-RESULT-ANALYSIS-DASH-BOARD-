# CBSE Class XII Commerce Result Analytics Dashboard

## What is included?
- `app.py` — complete dashboard code
- `data/sample_results.csv` — fictional demonstration dataset
- `requirements.txt` — Python libraries required
- `Project_Report.docx` — editable project report
- `Project_Presentation.pptx` — editable presentation
- `RUNNING_GUIDE.md` — beginner-friendly steps

## Important
The marks in the sample CSV are fictional. Do not submit them as real school data. The `Needs_Support` column is a demonstration rule only (any subject mark below 40); it is not an official CBSE pass/fail rule.

## Run without installing Python on your laptop
Use a browser-based environment such as Google Colab to learn Python basics. To run this Streamlit dashboard, use a cloud coding service that supports Streamlit, or ask a teacher/mentor to help set up Streamlit Community Cloud with the project files. You can also install Python later if you prefer running it locally.

## Expected CSV columns
`Student_ID, Student_Name, Section, English, Accountancy, Business_Studies, Economics, Informatics_Practices`

Marks should be numeric values from 0 to 100. Keep personal student information private; anonymised IDs are recommended.
